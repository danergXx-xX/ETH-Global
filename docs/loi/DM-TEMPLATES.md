## Universal anti-patterns (Maja review enforced)

NIE pisz:
- "Hope this finds you well" - delete
- "I hope you are doing well" - delete
- "Just wanted to reach out" - delete
- "Quick question" jako opener (chyba ze rzeczywiscie jest 1 pytanie)
- "Game-changing" / "revolutionary" / "next-gen" - hype slang
- "Synergy" / "leverage" / "circle back" - corporate
- Em-dashes - zamien na zwykly myslnik

Zawsze:
- Imie + 1 zdanie hook (concrete reference do ich pracy)
- Co my mamy + co to robi (2 zdania)
- Repo link
- Konkretny CTA (5 min look + 1-paragraph LOI)
- Sign-off neutralny ("Either way thanks" / "Thanks")
